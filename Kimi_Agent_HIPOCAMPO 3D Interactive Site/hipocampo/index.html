01 — O projeto

Toda imagem
é uma lacuna.

Uma pessoa desapareceu. Não sabemos se morreu, se esqueceu quem era ou se encontrou outra forma de existir. Restaram imagens, objetos e registros que já não explicam a si mesmos.

Recebemos sua história como se recebe uma lembrança alheia: oral, incompleta e atravessada por quem conta. Entramos juntos no intervalo entre recordar e inventar.

O que construímos não é a verdade dessa pessoa. É uma narrativa possível — o vestígio de um encontro entre aquilo que a imagem guarda e aquilo que cada olhar deposita nela.

até que ponto uma imagem
preserva uma memória?

02 — Como funciona

Entrar no
limbo.

Quatro gestos, nenhuma ordem definitiva. O roteiro existe apenas enquanto alguém o escuta.

  1. 01 / chegada

    deixar o nome do lado de fora

  2. 02 / escuta
    “Ela guardava o verão dentro de uma caixa. Ou era outra estação?”

    o roteiro não será repetido

  3. 03 / limbo

    aqui, lembrar é também fabricar

  4. 04 / montagem

    aproximar o que nunca esteve junto

03 — Instalação virtual

Entre na
sala.

A exposição se organiza como um espaço-limbo: quatro ilhas iluminadas, objetos sem legenda e uma história que só existe enquanto alguém toca, aproxima e desloca seus vestígios.

Arraste o fundo para mudar o ponto de vista. Toque nos objetos para ouvir o que eles sugerem e mova cada fragmento dentro de sua ilha.

arraste a sala para olhar ao redor · arraste os objetos para reorganizar
